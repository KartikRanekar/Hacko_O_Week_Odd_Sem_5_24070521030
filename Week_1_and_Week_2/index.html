About the Application

This is a modern Library Management System designed as an academic demonstration project. It is built as a Single Page Application (SPA) powered by a lightweight FastAPI backend and SQLite database to showcase real-time CRUD (Create, Read, Update, Delete) capabilities, state synchronization, and modular glassmorphic frontend styling.
